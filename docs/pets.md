# Making a pet pack

A pack is a directory of PNGs and one JSON file. No build step, no tooling.

```
~/.local/share/agent-pet/pets/
└── momo/
    ├── manifest.json
    ├── idle.png
    ├── thinking.png
    ├── working.png
    ├── attention.png
    ├── confused.png
    ├── worried.png
    ├── happy.png
    ├── celebrate.png
    ├── sleeping.png
    └── heart.png
```

Drop the directory in, restart `petd`, and the pack appears under
**Change Pet**. A pack whose `id` matches a built-in replaces it.

## Sprite strips

Each state is one PNG containing N frames of equal size, laid out left to right,
with alpha:

```
┌──────┬──────┬──────┬──────┐
│  f0  │  f1  │  f2  │  f3  │   40 × 160, four 40×40 frames
└──────┴──────┴──────┴──────┘
```

The renderer animates the strip with a single CSS `steps()` keyframe, so the
compositor does the work and an idle pet costs essentially no CPU. See
[ADR 0003](adr/0003-pet-asset-format.md) for why strips rather than animated
WebP.

Two to six frames is plenty. Slow rates read better than fast ones: the built-in
idle animation runs at 3 fps.

## manifest.json

```json
{
  "id": "momo",
  "name": "Momo",
  "version": 1,
  "author": "you",
  "description": "A small round cat.",
  "frame_width": 40,
  "frame_height": 40,
  "scale": 3,
  "pixelated": true,
  "animations": {
    "idle":      { "file": "idle.png",      "frames": 4, "fps": 3,  "loop": true },
    "thinking":  { "file": "thinking.png",  "frames": 4, "fps": 4,  "loop": true },
    "working":   { "file": "working.png",   "frames": 4, "fps": 8,  "loop": true },
    "attention": { "file": "attention.png", "frames": 4, "fps": 6,  "loop": true },
    "confused":  { "file": "confused.png",  "frames": 4, "fps": 5,  "loop": true },
    "worried":   { "file": "worried.png",   "frames": 4, "fps": 4,  "loop": true },
    "happy":     { "file": "happy.png",     "frames": 4, "fps": 6,  "loop": true },
    "celebrate": { "file": "celebrate.png", "frames": 6, "fps": 10, "loop": true },
    "sleeping":  { "file": "sleeping.png",  "frames": 4, "fps": 2,  "loop": true },
    "heart":     { "file": "heart.png",     "frames": 4, "fps": 5,  "loop": true }
  }
}
```

| Field | Default | Notes |
|---|---|---|
| `id` | directory name | Letters, digits, `-` and `_` only. |
| `frame_width` / `frame_height` | 40 | One frame, not the whole strip. |
| `scale` | 3 | Preferred pixel multiplier. Keep it an integer for pixel art. |
| `pixelated` | false | Nearest-neighbour scaling. Set it for pixel art; leave it off for smooth illustrations. |

An animation may also be written as a bare filename, matching the shape in the
original requirements document:

```json
"animations": { "idle": "idle.webp", "happy": "happy.webp" }
```

That means one frame. It loads, but it will not move.

## Missing states

You do not have to draw all eleven. Anything absent falls back:

```
sleeping  → idle
thinking  → working  → idle
working   → thinking → idle
attention → confused → idle
confused  → worried  → idle
worried   → confused → idle
happy     → celebrate → idle
celebrate → happy    → idle
heart     → happy    → idle
```

Only `idle` is genuinely required. `petctl doctor` lists what a pack is missing.

## Drawing advice, learned the hard way

The built-in packs are generated by `tools/genpets/genpets.py`; the shapes there
went through a few rounds before they read properly at 40 pixels.

- **Reserve a corner for props.** The `Z`, `!`, `?`, heart and coffee cup all
  live in the same top-right zone so they never collide with an ear or a tail.
- **Distinguish `working` from `sleeping`.** A single horizontal bar for eyes
  reads as "asleep". Focused eyes need a brow *and* a visible pupil.
- **Bob, and squash while bobbing.** A body that only translates looks like a
  sticker being dragged; deforming it by one pixel on the beat looks alive.
- **A ground shadow that shrinks as the pet rises** sells a hop more cheaply
  than extra frames.
- **`attention` should be visible from the corner of an eye.** A red `!` that
  blinks on alternate frames does more than any facial expression.

## Building a pack from a photo

The character pipeline is Milestone 5 and is not built yet. The design is local
image processing only — crop, palette reduction, procedural expression overlays —
with no AI service involved, so nothing leaves the machine and there is nothing
to opt into. Its output is exactly the format above, written into the user pets
directory, which is why that directory is already wired up here.
